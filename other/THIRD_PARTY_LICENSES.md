# 第三方授权汇总

## Godot Engine

本项目使用 Godot Engine 4.7.2 Standard 和 Compatibility 渲染器。Godot Engine
以 MIT License 发布；引擎源码和完整版权文本见 Godot 官方发行包。

## Noto Serif CJK SC

`source/assets/fonts/NotoSerifSC-VF.ttf` 为未修改的 Noto Serif CJK SC 可变字体，
依据 SIL Open Font License 1.1 发布。随字体提供的说明文件为
`source/assets/fonts/NotoSerifSC-VF-LICENSE.txt`；许可证正文见
<https://scripts.sil.org/OFL>。

## 项目素材

`image/` 与 `audio/` 中的项目素材随本项目内部测试包交付。若某项素材在最终公开版
改由外部素材替换，发布前应在这里补充来源、作者、版本和许可证。
