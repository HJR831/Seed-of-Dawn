# 7–13 小时基础系统试玩清单

## 跑图检查

1. 出生后确认序章文本逐字出现；连续经过多个触发区时，文本应排队而非覆盖。
2. 进入底层绿色黏液，移动应明显变慢；离开后应立刻恢复。
3. 靠近绿色沉睡者：轻按 E 应增加 `nurture`；重开后改为长按 E，应只增加 `devour`。同一局不能对它重复计数。
4. 碰到黄色日期石片，应自动拾取并显示文本；再次经过原位不能重复获得。
5. 长按 Space 撕开保鲜膜；叙事文本出现期间 Space 只负责跳字，不同时蓄力。
6. 进入第三幕右侧蓝色冰霜区，芽体与光应变成冰蓝色并减速；离开后恢复紫色。
7. 快速撞击瓶子或硬包装，应播放低沉碰撞提示并增加 `hard_collision_count`。
8. 到达顶部后长按 Space，确认仍能进入结局 01，再按 R 重开。

## F3 调试面板

Debug 构建中按 F3 打开。面板显示行为值、奶滴/霜晶/价签、压缩机次数、撞击计数，以及 items、flags、rituals。数字 1–4 可传送到四个关卡阶段，其余按钮可添加测试状态或清空图鉴。

正式 Release 构建中 `OS.is_debug_build()` 为 false，F3 不会打开面板。

## 当前占位内容

音效和压缩机低频目前由程序生成，目的是验证事件、总线与节奏。正式 WAV/OGG 到位后，应通过 `AudioManager.register_sfx()` / `register_music()` 按 ID 替换，不要让关卡脚本直接引用音频路径。
