# 13–20 小时阶段试玩指南

## 快速验证三个结局

### 结局 01：生长成功，食用失败

1. 按 F3，点击阶段传送数字 5。
2. 关闭 F3，向上靠近盒盖；若终幕文本正在显示，先用 Space 跳过。
3. 长按 Space 约 1.75 秒。
4. 确认标题正确，图鉴至少显示 1/12；按 R 后本局状态清空，但图鉴仍保留。

### 结局 02：万芽之主

1. 重开后按 F3，点击“给予古神配方”。
2. 点击“传送伪太阳”，关闭 F3。
3. 在冷白灯开关范围内长按 E 七秒，中途不要松开。
4. 确认紫黑结局画面、标题和正文正确。

自然路线中，腐败之眼在底层右侧黑水，猩红圣膏在泰坦瓶上方辣油，永冻之心在右侧冰霜区。围绕红色瓶体按上→左→下→右经过四个紫色检查点，完成逆时针仪式；压缩机第三次启动约在本局开始 24 秒后发生。

### 结局 03：奶龙降生

1. 必须先重开，避免上一局的腐化和辣油接触记录。d
2. 按 F3，点击“给予奶龙配方”。
3. 点击“传送小龙旧像”，关闭 F3，然后完全不按方向键静止三秒。
4. 确认金黄色结局画面、标题和正文正确。

自然路线中三滴奶分别位于腐土上层右侧、回声根网左侧和泰坦区左侧；日之金鳞在上层冰霜区左侧。黄色瓶盖仪式顺序为上→右→下→左。奶龙路线不能接触底层黑水或泰坦瓶上方辣油，也不能吸收三件腐败遗物。

## 大地图试玩重点

- 观察交替搁板是否形成清楚的左右折返，而不是让玩家误以为走进死路。
- 检查每幕两侧空间是否有探索欲，地标能否在局部光照边缘被发现。
- 记录自然跑到默认结局的时间、最容易迷路的位置以及觉得空旷的路段。
- 当前只完成前三结局，因此最终版 10–20 分钟目标还会由后续九条路线、互动和正式素材继续填充；本阶段不应通过降低速度制造时长。

## 存档位置

永久进度保存在 Godot 的 `user://save_data.cfg`。F3 的“清空结局图鉴”会立即写入存档，仅 Debug 构建显示该按钮。
