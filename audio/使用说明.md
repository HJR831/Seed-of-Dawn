# 冰箱冒险 · 原创合成音频资源包

共 87 个音频文件，覆盖需求中的全部条目及变体。音乐与环境声 OGG Vorbis；交互音效 WAV PCM 24-bit；共生层为可叠加 OGG。全部 48 kHz / 立体声。所有声音由程序合成，无外部录音采样。合唱为合成元音，幼龙为合成生物声，材质音效为拟音设计。

## 使用

- 打开「试听索引.html」逐项试听，或直接从 ambience / music / sfx 导入游戏。索引提供单项重复播放；浏览器循环不代表引擎无缝播放精度。
- manifest.json 提供英文稳定 ID、中文名称、优先级、精确样本数、循环范围、节拍及 SHA-256；资源清单.csv 可用表格软件打开。
- 循环范围均为 [0, frames)，结束位置不包含该样本。引擎使用解码后的 PCM 样本范围循环，不另加淡入淡出。OGG 不要按容器字节数或播放器估计秒数切割。
- 24 秒基础音乐和危险层均为 80 BPM / 8 小节 / D 小调，同一音频时钟同步播放，危险层用音量渐入；留出至少 6 dB 总线余量。
- 压缩机循环自带 0 秒启动标记：0、24、48 秒依次为前三次启动。不要再同时叠加独立启动声；事件判断使用引擎时钟，不做声音识别。
- 共生 A/B/C 为 D3/F3/A3，三个 24 秒层同步后构成完整 D 小三和弦，逐层 150–300 ms 渐入。唤醒音与对应层同音高。
- ROOT 循环每拍 0.75 秒，四拍一小节，第一拍低音重音。0/0.75/1.5/2.25 秒为首小节判定点，之后按 3 秒重复。
- 永冬提供单次、40/20/10 BPM 三种循环及 30 秒逐渐变慢演出版。交互玩法优先调度单次心跳，避免直接拉伸音频造成音高下降。
- 门外脚步远/中/近保留真实音量梯度；旧神眼睛保留三档强度。不要对各文件再次统一峰值。
- 庄严和弦在 2.72 秒收住，余下 0.48 秒静默；此处可触发干声盒扣，再接 8-bit 短调。短调总长 4.8 秒，留有干净结束点。
- 移动停止用 60–100 ms 淡出移动循环，同时播放停止尾音；保鲜膜蓄力可把循环播放速率从 1.0 平滑提高至 1.4。

## 校验与范围

所有交付文件均重新解码，检查 48 kHz、双声道、样本数、非静音、无削波和循环接缝；结果见 validation.json。OGG 为有损格式，解码峰值可能与目标峰值略有差别。完成的是程序合成资源；未进行人工逐项听审或游戏内混音验收。

额外提供「audio_preview_montage.wav」作为代表性音色预览；不属于游戏资源条目。

## 文件命名对齐

已按 need(4).md 第 7 节的固定英文文件名交付。8-bit 小调与三个共生层已由 WAV 实际转为 OGG；其余音频保持原字节内容。永冬的逐渐减慢演出使用 amb_eternal_frost_heartbeat.ogg，单次与三档循环加用途后缀；第七格补充声使用 sfx_thermostat_click_seventh.wav。文件重命名对照见 rename_map.csv。
